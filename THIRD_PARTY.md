# Sources and attribution

BranchLab is an independent, AI-assisted educational/research project. It is not an official Stanford submission, course solution release, Marin implementation, or Stanford/Open Athena affiliation claim. The implementation is original project code inspired by standard Transformer components and the CS336 learning agenda.

- **TinyStories**: Ronen Eldan and Yuanzhi Li, [dataset](https://huggingface.co/datasets/roneneldan/TinyStories), [paper](https://arxiv.org/abs/2305.07759). The pinned dataset card declares **CDLA-Sharing-1.0**. The source data is fetched from its original host; this repository does not redistribute the corpus. Revision, source hash and local repartition procedure appear in `src/branchlab/data.py`. Generated weights are supplied separately as an experimental result; see the model card.
- **Marin / Delphi**: [Open Athena Delphi](https://openathena.ai/blog/delphi/) and [public table repository](https://huggingface.co/datasets/marin-community/delphi-blog-data). The repository distributes file identities, field inventories, hashes and derived aggregate counts, not the source parquet tables. Source availability is distinct from permission to relicense data; BranchLab's MIT license covers its own code and documentation.
- **CS336**: [Stanford Spring 2026 course](https://cs336.stanford.edu/). This project independently implements byte BPE, a decoder-only Transformer, RoPE, RMSNorm, SwiGLU, AdamW, checkpoint restoration and KV-cache decoding. No claim of passing course assignment tests is made.
- Dependencies retain their own licenses: PyTorch, NumPy, PyArrow, Matplotlib, pytest, setuptools and build. `requirements-tested.txt` records the tested direct versions; normal installation uses compatible version ranges.
