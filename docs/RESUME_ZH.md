# 简历表述与证据要求

项目名称建议：**BranchLab：从零实现 Transformer 与训练诊断程序搜索实验**。

下面是待实测报告填充的模板。方括号内必须来自发布产物；尚未测得的
数字应删去，不应沿用参考图片或其他项目的数字。运行报告命令后查看
`reports/release/resume_zh.md` 中基于实际产物生成的版本。

> - 参照 Stanford CS336 的语言模型工程路线，从零实现 byte-level BPE、
>   causal attention、RoPE、RMSNorm、SwiGLU、AdamW、完整训练恢复与 KV
>   cache，在明确划分的数据子集上完成〔参数量〕参数模型的〔训练 token
>   数〕token 训练；开发集交叉熵由〔初始值〕变为〔最终值〕。
> - 在〔设备、精度、batch、输入长度、生成长度〕的固定条件下，验证
>   cached/uncached logits 一致性，并测得解码吞吐〔基线值〕→〔缓存值〕
>   tokens/s；报告预热、同步、多次测量和独立 prefill 开销。
> - 实现由 18 项短干预探针组成的有限诊断语言、反例优先搜索和最多两个
>   探针的逐代继承；在 discovery/development/test 隔离的〔episode 数〕
>   个本地训练状态上，与免费日志、固定专家、随机搜索和枚举比较，
>   取得〔实际正结果、负结果或不确定结果〕。
> - 建立模型/优化器/RNG/数据位置恢复、逐查询预算账本、固定版本公开数据
>   审计与可重复发布流程；区分真实全分支采集成本、重放成本和部署诊断
>   成本，并保留失败结果。

有结果后也必须保留这些边界：

- 开发集 loss 降低说明该次训练实现可运行；不能换写成最终测试集成绩。
- KV cache 结果适用于报告中的模型和测速配置；它与训练收益、RSI 收益无关。
- 有限候选的程序搜索可写“实现”或“比较”，不应直接写“首创自动发明算法”。
- 若同预算枚举、随机或固定专家更好，如实写“未发现反例排序优势”即可。
- 公开 Delphi 终点表与本地分叉实验分别列出；不能写“复现 Marin 大模型
  完整训练轨迹”。
- 当前实现未修改合成器本身，不使用“实现递归自我改进”“验证 RSI”或
  “达到 SOTA”。

只有亲自理解并能讲清楚对应代码、测量设置和结果，才应将条目用于个人简历。
